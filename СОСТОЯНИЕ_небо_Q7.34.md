## 1. Компонентная архитектура неба (текущая, фактическая)

| Компонент | Файл(ы) | Ответственность |
|---|---|---|
| Хост-шейдер | `SkyEnvironment.gdshader` | градиент (44 ramp-uniform'а, палитра palletes.html байт-в-байт), солнце/луна/звёзды, **4 контрактных uniform'а вуали** (`cloud_light_color`, `cloud_light_strength`, `cloud_ambient_sky_color`, `cloud_ambient_energy`), `#include` модуля вуали — **ОБЯЗАТЕЛЬНО после всех uniform-ов хоста** (якорь: после `uniform float moon_detail_int`) |
| Вуаль (модуль) | `SkyVeil.gdshaderinc` | 42 uniform'а `hc_*`/`veil_*`; одна плоская плита, ОДИН сэмпл плотности на луч, без marching/powder/MS/погодных масок; композит в scene-linear ДО filmic round-trip; вуаль ПЕРЕД солнцем/луной/звёздами |
| Данные вуали в пресете | `SkyVeilProfile.gd` | sub-resource, 8 живых полей (компонентный порядок заказчика: отдельный модуль + загрузчик + sub-resource вместо 8 плоских полей пресета) |
| Пресет | `SkyPreset.gd` + `SkyPreset/Preset_01..10.tres` | всё состояние неба; `light: SkyLightProfile` (**к удалению**, §4); class-default `veil_enabled=false`, `breathe=0.0` — чтобы .tres несли явные `veil_enabled = true`, `breathe = 0.9` (ResourceSaver не пишет равные дефолтам поля!) |
| Ссылочные пресеты | `SkyPresetRefs/` (создаётся при первом сохранении) | именованные слепки текущего состояния ВКЛЮЧАЯ живую вуаль (задача 1, 3.2.14) |
| Контроллер | `SkyEnvironmentController.gd` | **единственный писатель uniform'ов** (`set_shader_param`); `apply_preset` (вуаль НЕ трогает с 3.2.14), `apply_veil`, `apply_sources` (геометрия Sun/Moon → DirectionalLight3D + `sk_sun_dir`), `_ready` — один старт вуали из `initial_preset`; делегирует свет/tonemap в `SkyLightController` |
| Панель | `SkyControlPanel.gd` | 7 вкладок: Градиент(0)/Источник(1)/Купол(2)/**Свет сцены(3 — к удалению)**/Погода(4)/Пресеты(5)/Отладка(6); «Погода» = живые ручки вуали + ветер + «Сброс вуали (к дефолтам компонента)»; «Пресеты» = штатные + референсные списком; extends CanvasLayer, 4-space ТАБЫ, `:=` из Variant = parse error (warnings-as-errors) |
| Старый свет | `SkyLightController.gd`, `SkyLightProfile.gd` | **текущий свет — к удалению по решению заказчика** (§4); ВАЖНО: контроллер также владеет геометрией Sun/Moon (углы→basis, enabled) и `tonemap_linear` — эта часть СОХРАНЯЕТСЯ (добро заказчика, п.4) |
| Валидатор | `SkyPresetValidator.gd` | правило 4 «light не задан» — к удалению вместе с полем light |
| Текстуры | `CloudTextureLoader.gd`, `noise_*.bin`, `moon_detail.png`, `streak_glare.png` | загрузка шумов/деталей |

**Гигиена кубемапы** (Godot: любой uniform → пересборка radiance cubemap):
никаких per-frame CPU-записей; ветер живёт ТОЛЬКО на shader `TIME`
(`hc_wind_timelapse`); все записи — событийные (apply_* / publish()).

**Геометрия (standing)**: дистанция ≥90 км (MAX_SAMPLE_DIST 100000, потолка нет —
float32 ок); плита ≥3× поднята; curtain по PATH 18000/55000 (не по дистанции
камеры — иначе «диск над головой»); fisheye fov 93° (прямой заказ); streak — Б-мир.

- Освещение вуали сейчас: `direct = veil_light_ramp_color(cos_theta) * (cloud_light_strength * shade * shadow_t) * hc_light_gain`; `ambient = cloud_ambient_sky_color * (cloud_ambient_energy * hc_ambient_gain)`; итог `hc_color * (direct + ambient)` → **`hc_color` = альбедо/материал, не эмиссия** (соответствует §7.3 нового плана — заказчик: «супер»).

- Семантика 3.2.14: выбор пресета вуаль НЕ сбрасывает; старт — один `apply_veil(initial_preset)` из `_ready`; единственный сброс — кнопка «Сброс вуали» (25 VEIL_DEFAULTS через контроллер; `get_shader_parameter` возвращает null для незаписанных uniform'ов — панель читает только через `_veil_get`+VEIL_DEFAULTS).
- Свет вуали НЕ реализован (заказ): палитры/цвета заморожены на дефолтах; «мы не можем фиксить свет, мы его не реализовывали».

## 4. СВЕТ — решения заказчика (30.10, этот чат) и план

Новый контракт: **`СВЕТ_план_Q7.34.md`** (= Light_plan.txt, байт-в-байт в репо).
Кратко: Sun — единственный активный источник (направление/цвет/интенсивность);
Sky Gradient — цветовая среда (ambient-заливка, НЕ второй источник); Cirrus Veil —
потребитель (плотность/оптическая толщина/самозатенение/рассеивание, **без эмиссии**).
Запрещены: эмиссия вуали/земли/горизонта, захардкоженные доп. источники, независимые
цветовые поправки. Moon — единственное исключение, в реализацию пока НЕ входит.

### Решения по моему анализу конфликтов (заказчик, 30.10):
1. **В РАБОТУ, в «нерешённое»**: снэппет плана §4.5 вызывает палитру от
   `cloud_light_direction`, которого больше нет (удалён в H1). На этапе 04 палитра
   вызывается от `sk_sun_dir` (§7.1 — единственный владелец направления). Не
   reintroduce'ить второй источник направления.
2. **Одна рампа — ГДЕ (ответ, зафиксирован)**: рампа живёт **в компоненте вуали**
   (`SkyVeil.gdshaderinc`) — это данные вуали. Входные uniform'ы поставляет
   единственный `AtmosphereLightingProfile` через `CirrusVeilBinding`; старый
   хост-контракт (`cloud_light_color` и пр.) поглощается новым контрактом и
   удаляется на этапе 04. Второй рампы в хосте/градиенте НЕТ.
3. **Свет удали, Луну оставь и пометь как временная заглушка**: MoonLight
   (DirectionalLight3D) и визуальный диск луны СОХРАНЯЮТСЯ с явной пометкой
   «временная заглушка до интеграции Moon (исключение §2 плана)» — в коде
   (комментарии) и в доках. Остальной текущий свет — удалить.
4. **Граница удаления — СОГЛАСОВАНО («даю добро»)**: удалить `SkyLightProfile`
   (key/moon/ambient color+energy), `apply_light`-цепочку, вкладку «Свет сцены»,
   поле `light` в `SkyPreset`/валидатор(пр.4)/10 .tres (миграция по образцу
   `migrate_breathe_max.gd`). `SkyLightController` СОХРАНЯЕТСЯ как владелец
   геометрии Sun/Moon (углы→DirectionalLight3D, enabled) и tonemap.
5. **Писатели**: binding-компоненты нового света пишут ТОЛЬКО параметры освещения;
   **форма и вуаль остаются за `SkyEnvironmentController`** (подтверждено).
6. **`hc_color` = альбедо** — принято («супер»), изменений не требует.

### Новый свет — состав (план §4, пути заказчика: `SkyEnvironment/Scripts/`)
- `AtmosphereLightingProfile.gd` (Resource): 3 цвета угловой палитры вуали
  (anti_solar/transition/solar), `anti_solar_mu=-0.35`, `solar_mu=0.75`,
  `transition_position=0.5`, `direct_multiplier`, ambient zenith/horizon color +
  `ambient_strength`. Ресурс: `res://SkyEnvironment/Profiles/AtmosphereLightingProfile.tres`.
- `AtmosphereLightingState.gd` (RefCounted) — контейнер, ничего не считает.
- `AtmosphereLightingComponent.gd` (Node) — читает существующий `DirectionalLight3D`
  (Sun): направление = `global_basis.orthonormalized().z.normalized()` (НА источник;
  лучи вдоль −Z), цвет, энергия×direct_multiplier; `publish()` — событийно (без
  `_process`/polling), сигнал `lighting_changed(state)`. Вызывается владельцем
  трансформации Sun после её изменения.
- `AtmosphereShaderBindingComponent.gd` (Node) — один экземпляр на ShaderMaterial
  (SkyGradientBinding + CirrusVeilBinding); имена uniforms — данные (@export);
  пишет только существующие (`get_shader_uniform_list`-кэш); слушает сигнал.
- GLSL вуали (этап 04): `hc_angular_palette(view_dir, sun_dir)` — 3 зоны по
  `mu = dot(view, sun)` с плавными переходами (smoothstep через middle);
  uniform'ы `hc_palette_anti_solar/transition/solar` + mu-параметры; tint —
  художественный множитель цвета ПРЯМОГО света (`sun_col * palette_tint * …`),
  НЕ трогает `hc_density()/hc_coverage/hc_tau_per_km`. Стартовые tint (§4.5):
  anti-solar `0.78,0.86,1.00`; transition `1.00,0.94,0.86`; solar `1.00,0.78,0.56`
  (мягкие, околобелые). Палитрные цвета проекта — из palletes.html (байт-в-байт).
- Структура сцены (план §5): `World/SkyEnvironment/{AtmosphereLightingComponent,
  SkyGradientBinding, CirrusVeilBinding}`, `DirectionalLight3D (Sun)`, `Camera3D`.
- Производительность (§6): без полного ray marching; односэмпловая модель вуали
  сохраняется; самозатенение — отдельный ОТКЛЮЧАЕМЫЙ блок; обновления по сигналам.
