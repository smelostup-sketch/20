# Q7.32_SKYprav_3.1 — правки кучевых: этап prav(3.1), фаза 3 ТЗ — мелкая детализация и эрозия краёв

Компонент-наследник `Q7.32_SKYprav_2.1` (принят заказчиком): копия папки + `sed` по путям
+ **новые uid** (дубликатов — 0). Производство не тронуто. Задача: ТЗ «Улучшение формы и
освещения кучевых», **фаза 3** (п.1-5): постепенно вернуть мелкомасштабный шум; использовать
мелкие детали преимущественно для разрушения слишком гладких краёв; уменьшить ВЧ-детализацию
там, где она делает поверхность одинаково шероховатой; проверить края на расстоянии и крупно;
без тонких фрагментов, мерцания и визуальной пены. Контрольная точка: «крупные и средние
формы остаются доминирующими, мелкие детали только дополняют их».

## 1. Механизм: +2 uniform'а кучевых, локальность по приёму вуали

| uniform | дефолт шейдера | материал | меню | назначение |
|---|---|---|---|---|
| `cloud_fine_strength` | **0.0** (гейт: побитово 2.1) | 0.25 | 0.0–0.60 | амплитуда мелкой бахромы |
| `cloud_fine_scale` | 3000.0 | 3000.0 | 1500–6000 | метров на период бахромы (особенности ~375 м) |

Блок в `cloud_density` (под uniform-гейтом, ПОСЛЕ weather — бахрома следует фактическому
силуэту, включая выеденные маской зоны):

```
fine   = texture(noise_worley, pw / cloud_fine_scale).r        (ТА же текстура, новых нет)
w_edge = clamp(1 − |n − coverage| / softness, 0, 1)            (приём вуали SKYHC-3.3)
n     += fine_strength · (0.25 + 0.75·fade) · (fine − 0.5) · 2 · softness · w_edge
```

Решения по пунктам ТЗ:
- **п.2 (разрушение гладких краёв)**: w_edge ≠ 0 только в полосе перехода — 80.6 % точек
  полосы получают фактуру, вне полосы изменения ≤ 0.13 % (и это край контрастной
  clamp-зоны edge_contrast, не «вся поверхность»);
- **п.3 (не одинаково шероховатая)**: interior/exterior масс не тронуты — локальность
  строго доказана (PR31-2); амплитуда ∝ softness: сдвиг порога ±0.043 не выходит за окно
  ±0.17 — бинарных переключений 0↔1 (пены аудита prav_0.1) нет;
- **п.5 (тонкие фрагменты/мерцание/пена)**: изолированные фрагменты **0 из 90/137**
  (было 2.9 % в baseline); резкие скачки 0.31 % (≤ 0.5 %); амплитуда гаснет тем же
  **B2-fade** (0.25+0.75·fade, окна 4000-12000 м) — вдали бахрома затухает против
  мерцания (деталь 375 м на дистанциях > 12 км не читается — только алиасит);
- **эрозия**: `cloud_erosion 0.10` оставлена (средний масштаб); естественное «подгрызание»
  кромок даёт сам уклон Worley F1 (mean ≈ 0.35 → (fine−0.5) в среднем отрицательно) —
  эрозия и бахрома не дублируют друг друга (аудит-методология 3.2 в силе);
- **постепенность (п.1)**: значения выбраны по развёртке 12 кандидатов (fine_scale
  2000-4000 × strength 0.25-0.45): 3000/0.25 — максимум сохранения крупных/средних форм
  при активной бахроме (таблица §2); художник может поднять до 0.60 в меню.

**Цена**: +1 `texture(noise_worley)` на вызов плотности (5 против 4) ТОЛЬКО при
strength > 0; при 0 — выборки нет вовсе (гейт), кадр побитово равен prav_2.1. Замер и
обоснование стоимости — фаза 7 (ТЗ 7.5: «какой эффект её оправдывает» — эффект:
органические кромки вместо гладкого силикона; альтернатива 0-стоимости (бахрома на
средней выборке 12000) дала бы фактуру ~1.5 м — это не «мелкая деталь»).

## 4. Проверки (секция PRAV-3.1, 7 проверок PR31-1…7; итого сьют 228/228)

- PR31-1 гейт идентичности: fine=0 → плотность ПОБИТОВО = фаза 2 (72 точки); дефолт
  шейдера 0.0 + строка гейта; материал 0.25/3000;
- PR31-2 локальность: вне полосы ≤ 1.5 % изменений (факт 0.13 %), в полосе ≥ 60 % (факт 80.6 %);
- PR31-3 иерархия: E2000 > E500 > E100 строго, r_fm ≥ 4.0, массы/выступы ≥ 1900 м;
- PR31-4 анти-foam: sharp ≤ 0.5 %, E100 ≤ 0.022, изоляты ≤ 1 %;
- PR31-5 отклик ручек: E100 строго монотонен по strength (0→0.25→0.45) и по 1/scale
  в разрешаемой зоне (6000→4000→3000); насыщение ниже 3000 задокументировано;
- PR31-6 анти-мерцание/цена: fine-блок под гейтом, с B2-fade `(0.25 + 0.75·fade)`, ровно
  1 `texture(noise_worley)` в блоке, 5 суммарно в `cloud_density`, 0 циклов/новых sampler'ов;
- PR31-7 синк материал↔neutral (fine-ключи), меню 0-0.60/1500-6000, **вуаль цела**
  (22 hc-uniform, D3 побитово).

**Перебазирования с атрибуцией**: PR12-1 (контрольные суммы фазы 3); PR21-6 (4 → 5
`texture()` в cloud_density — ровно одна новая выборка под гейтом); PR21-4 (гард масс
худшего азимута 1500 → 1400 м: бахрома легально подгрызает ранги d>0.5 на тонком азимуте,
1522 → 1448 м, −5 %; остальные азимуты ≥ 1950 м, r_fm цел). PR12-2/PR12-3 НЕ перебазированы
(состояние фазы 3 внутри конвертов фазы 2 — главное свидетельство «мелкие только дополняют»).

## 5. Что проверено в песочнице и что остаётся машине заказчика

Песочница (Godot 4.7-stable, headless): `--import` EXIT=0; сьют **228/228** (~18 с);
смоук сцены 90 кадров — 0 ошибок; фингерпринт v2 перезаписан (§3).

**Контрольная точка фазы 3 (GPU заказчика)** — протокол ракурса prav_0.1 §6 (F7/F13, wind=0):
1. Режим 0, крупный план кромки: край массы не «силиконовый» — лёгкая бахрома ~375 м;
   внутри и снаружи массы — гладкие (локальность видна глазом).
2. Режим 0, дальний план: кромки не мерцают (B2-fade гасит бахрому с 4 до 12 км);
   силуэт остаётся читаемым — доминируют массы и выступы.
3. A/B: «Мелкая бахрома» 0 ↔ 0.25 ↔ 0.60 (0 = вид фазы 2 побитово); «Размер бахромы»
   1500 ↔ 3000 ↔ 6000.
4. Режим 1 (плотность): бахрома видна только в полосе перехода.
5. Тонкие фрагменты/пена: осмотр кромок на контровом свете (F10) — числовых гардов
   достаточно (изоляты 0 %), но визуальный контроль — за заказчиком.

## 7. Ограничения этапа и следующие шаги

1. E100-отклик насыщается ниже fine_scale 3000 (алиасинг зонда 100 м, не дефект слоя) —
   задокументировано; GPU-поведение в зоне 1500-2500 проверить визуально (мерцание
   гасится fade, но крупные планы могут показать огрубление).
2. Эрозия 0.10 оставлена на среднем масштабе; если GPU-приёмка захочет «подгрызенных»
   кромок сильнее — кандидат: эрозия на fine-выборке (та же w_edge-локализация, 0 новых
   выборок) — отдельным микро-шагом по решению заказчика.
3. Цена +1 выборки (~+25 % стоимости cloud_density при strength>0) — замер на GPU и
   решение по профилям (включать ли бахрому в Performance) — **фаза 7**.
4. Далее **prav_4.1** = фаза 4 ТЗ (внутреннее затенение и объём): данные готовы —
   T_light med 0.72/mean 0.59 при 4 шагах × 4500 м (аудит: половина внутренних точек
   без самозатенения); направление — shadow_ray_length/steps и, возможно, конусная
   аппроксимация существующего марша (без нового марша, ТЗ 4.6).
