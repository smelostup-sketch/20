# Q7.32_SKY_D3 — правки читаемости (по итогам просмотра D2)

Компонент-наследник `Q7.32_SKY_D2` (sed по путям). Производство НЕ тронуто.
Две правки по замечаниям заказчика + инструменты их настройки в меню (клавиша 9).

## 1. Переход зенит→горизонт и кольца палитры — чётче (вопрос заказчика №1)
Замечание: «слишком плавный переход» — цветовые зоны палитры размывались в одно пятно.
Добавлен `sky_grad_sharp` (дефолт 2.2): симметричная S-кривая поверх каждого окна сборки
градиента `sky_gradient()` (вертикаль + 4 угловых кольца вокруг солнца):

    b   = sstep(lo, hi, x)                 # окно палитры (как в D1/D2)
    S   = b^s / (b^s + (1−b)^s),  s = max(sky_grad_sharp, 0.25)
    s == 1 → S = b, побитово D2 (uniform-гейт идентичности)

s>1 сжимает переход к середине окна: цветовые зоны (горизонт/зенит, антисолнце, среднее
кольцо, розовое, бело-жёлтое) становятся различимыми, границы — чёткими, без «полосатости»
(концы окна и середина сохраняются точно, монотонность не нарушается).
Отбор дефолта: A/B s ∈ {1.0, 1.6, 2.2, 3.0} (`d3_grad_s*.png`): 1.6 — едва заметный эффект,
3.0 — кольцо у солнца читается отдельным «диском» (жёстко), 2.2 — зоны различимы, переход
остается воздушим. Меню: блок «Небо: градиент по палитре», строка «Резкость градиента» (0.5–4).

## 2. Контур облаков — твёрдый, с чёткой границей (вопрос заказчика №2)
Добавлен `cloud_edge_contrast` (дефолт 2.0): контрастная кривая поля плотности вокруг 0.5
ПОСЛЕ порога покрытия и ДО высотного профиля/curtain:

    d = sstep(coverage−softness, coverage+softness, n)   # как в D2
    d = clamp((d − 0.5)·max(cloud_edge_contrast,0) + 0.5, 0, 1)   # 1.0 → побитово D2

Полоса перехода «прозрачно→плотно» сужается в ~edge раз: силуэт массы становится твёрдым,
контур читается, тонкая дымка не съедает границу. Кривая видна и в основном марше, и в
теневых лучах (light_transmittance берёт то же поле) — тени согласованы с силуэтом.
0 и 1 — неподвижные точки (чистое небо/ядро массы не меняются).
Отбор дефолта: A/B e ∈ {1.0, 1.5, 2.0, 2.6} (`d3_edge_e*.png`): 1.5 — мягковато,
2.6 — тонкая бахрома масс исчезает, 2.0 — твёрдый контур с сохранённой бахромой.
Меню: блок «Облака: размер и количество», строка «Твёрдость кромки» (0.5–3).

## 3. Попутные починки зеркала (расхождения, найденные при правках)
- `_material_sp`: `ms_sun_gain`/`ms_amb_gain` читались константами 0.30/0.60, хотя с D2 они
  uniform'ы (0.45/0.60) → марш-зеркало расходилось с GPU; теперь читаются из материала,
  добавлен `use_ms2`; fallback'ы powder/ms_strength приведены к дефолтам D2 (0.3/0.65).
- `_material_lp`: дочитаны параметры C5a/C9 (`use_dual/hg_g2/dual_mix/diffuse_mix/use_ramp/
  ramp_*/use_amb_sky/amb_gain`) и вся палитра градиента с `g_sharp` — раньше зеркало брало
  рекорд-дефолты и могло разойтись с GPU при включённых рампе/градиенте из меню.

## 4. Регрессия и идентичность
- `sky_grad_sharp = 1.0` и `cloud_edge_contrast = 1.0` → побитово D2 (шейдер: uniform-гейты
  `s == 1.0` / `!= 1.0`; зеркало: те же гейты). Проверки сьютa: D3-1/D3-2 (S-кривая),
  D3-3a (grad_sharp=1 ≡ цепочке D2), D3-4a/b (edge=1 ≡ D2, кривая (d−0.5)·2+0.5).
- Сьют: 115/115 из поставленного пути (`_selftest/test_q732_num.gd`).
- GPU-смоук: Vulkan (llvmpipe) — 6 A/B-кадров (grad/backlit/antisun × D2-вид/D3-дефолты),
  GL3 — кадр без артефактов (`d3_gl3.png`). Замеры стоимости в песочнице не производились
  (llvmpipe не отражает цену на целевом GPU): обе правки — 1–2 арифметических операции на
  сэмпл/окно, порядково бесплатны относительно марша.

## 5. Состав и запуск
Файлы — как в D2 (14 + `_selftest/`): шейдер, стенд `CloudsTestBench.gd` (меню 9, пресеты
F10–F14, профили F6–F9), материал/небо/сцена, загрузчик текстур, генератор шумов, .bin,
README, uid'ы, численный сьют. Запуск сьютa:

    godot --headless --path <проект с компонентом> --script res://Q7.32_SKY_D3/_selftest/test_q732_num.gd

Инциденты сборки: вложенный каталог-артефакт `Q7.32_SKY_D3/` внутри компонента (опечатка cp)
удалён до упаковки; состав сверен с D2 (`diff` списков пуст).
