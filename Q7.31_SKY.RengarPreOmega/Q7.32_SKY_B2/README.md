# Q7.32_SKY_B2 — Volumetric Cumulus: density shaping (фаза B, этап B2)

Компонент **кумулятивен и самодостаточен**: заменяет `Q7.32_SKY_B1` целиком
(удаляете старую папку компонента → распаковываете эту в корень проекта, где `project.godot`).
Внутри всё ссылается через `res://Q7.32_SKY_B2/…`.

Продакшн-файлы не трогаются: `omega_sky_shader.gdshader`, `omega_sky_material.tres`,
`omega_sky.tres`, `Сцена_неба.tscn`, `Основная_сцена.tscn`. Основная сцена остаётся на небе A1.

## 1. Что добавлено относительно B1

1. **Вертикальная когерентность** (`cloud_vertical_stretch`, дефолт 2.5): базовое PW-поле
   семплируется с растяжением по Y — массы стали вертикально связными столбами;
   «расслоение» 3D-жилами по Y (наблюдение B1) устранено. Метрика: средняя |Δd| между
   y=1800 и y=2900 в 16 колонках = 0.144 (порог 0.25).
2. **Эрозия краёв** (`cloud_erosion`, дефолт 0.40): `n -= erosion·(1−detail)·(1−shape)` —
   деталь (Worley) съедает оболочку массы, ядра сохраняются. Причинная проверка: внутри
   базовой оболочки base∈[0.45,0.75] точки с низкой деталью съедаются в 58% случаев,
   с высокой — в 4% (r_lo=0.58 / r_hi=0.04).
3. **Distance-fade детали** (`detail_fade_start=4000`, `detail_fade_end=12000`): эрозия и
   выступы гаснут с дистанцией, где сегмент марша (469 м при 64 шагах) длиннее фич детали —
   лечение алиасинга дальнего поля без роста стоимости.
4. **Перегенерированное PW-поле** (тот же seed 1337 + wrap-блюр 3³): жилы PW смягчены —
   главный источник пиксельных скачков на дальних силуэтах. Новый sha256
   `noise_pw_128.bin` = `fb3554a4…`; `noise_worley_32.bin` не изменён (`eb75350d…`).
   Бесшовность после блюра: seam_ratio 0.955 (<1.5).
5. **Режим изолированных масс** вместо перколяционного «листа» (проблема A8/B1):
   `cloud_coverage` перекалиброван по рендер-метрике «доля синевы»: дефолт 0.42 даёт
   blue=0.46 (Vulkan) / 0.51 (GL3) при цели [0.35,0.75]; точечные доли: clear 90%, ядра 5%.
6. **Дефолтный питч камеры стенда +20°** (в B1 был −10°, показывавший насыщенный горизонт).
7. Ветер: без изменений (CPU-дрейф `cloud_offset`, `wind_speed=0` по умолчанию;
   F6 → Bench → Wind Speed 40–80 → массы плывут; H — печать drift/шагов/T).

## 2. Установка

1. Удалить `Q7.32_SKY_B1/` (и любые более ранние компоненты фазы B) из корня проекта.
2. Распаковать `Q7.32_SKY_B2.zip` в корень проекта (папка с `project.godot`).
3. Открыть проект в Godot 4.7 (дождаться импорта), открыть
   `res://Q7.32_SKY_B2/Сцена_облаков_тест.tscn`, F6.
4. В Output ожидается строка `[Bench] текстуры собраны из .bin за N мс (pw=128³ wo=32³)`.

Признаки, что запущен именно B2: в Output строка bench выше; в Inspector материала —
параметры `cloud_erosion`, `cloud_vertical_stretch`, `detail_fade_start/end`;
питч камеры сцены +20°; небо = изолированные массы на синем (не белый лист).

## 3. Параметры (новые в B2)

| uniform | дефолт | смысл |
|---|---|---|
| `cloud_coverage` | 0.42 | порог покрытия (калиброван под изолированные массы) |
| `cloud_erosion` | 0.40 | сила эрозии краёв деталью (0 = гладкие массы) |
| `cloud_vertical_stretch` | 2.5 | растяжение PW по Y (вертикальная связность) |
| `detail_fade_start/end` | 4000/12000 | дистанции гейта детали (алиасинг-контроль) |

Остальные uniform — как в B1 (`cloud_base_scale` 16000, `cloud_detail_scale` 1200,
`cloud_softness` 0.12, `cloud_detail_strength` 0.18, `cloud_extinction_scale` 0.0025,
`cloud_march_steps` 64, `cloud_max_ray_length` 30000, `cloud_early_exit` 0.01,
`height_base_fade` 0.15, `height_top_fade` 0.35, `cloud_offset`, `debug_mode` 0–6).

## 5. Журнал инцидентов (честно)

1. **CPU-зеркало ≠ GPU-семплер в «смешанной» точке по detail-члену**: при побайтово
   одинаковых .bin извлечение дало shape 0.296/0.271 (близко), но det 0.679/0.828
   (расхождение); перебор 24 комбинаций ориентаций/центровок текселей не нашёл соответствия.
   Следствие: зеркало остаётся инструментом ФИЗИКИ марша (интервалы, сохранение энергии,
   сходимость, непрерывность — все сходятся) и статистик поля; field-level приёмка
   переведена на рендер-метрики (доля синевы, огибающая, порядок режимов). Расхождение
   не зависит от драйвера (VK и GL3 согласны между собой по структуре проверок).
2. **Алиасинг марша на деталь-фичах**: сегмент 469 м против фич 150 м давал скачки
   T 0.00→0.92 между соседними пикселями (max|Δ1px| rel до 0.51). Лечение: distance-fade
   детали + блюр жил PW → остаток 0.10–0.16 = крутизна честных силуэтов (3–6 px переход);
   метрика звона заменена на осцилляции 8px-масштаба (звон = осцилляция, силуэт = монотонный
   переход). Полное лечение — jitter+TAA/reprojection: вне объёма Q7.32 (§9 ТЗ), крючок в Q7.33.
3. **ImageTexture3D.create(mipmaps=true) из Array[Image] не работает в 4.7**
   («Missing Images», неинициализированный RID) — аппаратный LOD детали недоступен;
   выбран ручной distance-fade.
4. Холодный импорт полного проекта в песочнице (1 ГБ RAM) дважды убит OOM; доведён
   «лесенкой» (частичный кэш между попытками), итог exit 0, 0 ошибок, 143 ресурса.
5.Lavapipe-артифакт середины тона (документирован с A4) сохраняется: режим 6, scenic-зенит
   0.886 (VK) против 0.718 (GL3) при mirror 0.573 — на реальных GPU (A4–A7, B1) не воспроизводился.

## 6. Известные ограничения B2 (для B3–B7)

- Освещения нет: массы белые/плоские (B3: солнце+HG+амбиент, B4: самозатенение/пудра/MS).
- Вертикальные «столбы» stretch заметны на средней полосе кадра (конгруэнтно цели
   вертикальной связности; кандидат на смягчение в B6 через анизотропию профиля).
- Краевая «пунктирность» эродированных кромок на средних дистанциях (4–12 км) —
   остаток алиасинга детали; смягчается шагом (B6) и TAA (Q7.33).
- debug_mode 0–6 наследуется B1; режимы 7–8 и честный пропуск вычислений — B5.
