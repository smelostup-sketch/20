## 4. Решения по панели (фаза F)

- **Алгоритм 13.4**: пример ТЗ внутренне противоречив (процентный пересчёт при замке даёт сдвигlocked-стопа). Реализовано: cell-local пропорциональное масштабирование групп между ближайшими замочками — locked-стопы неподвижны, остальные масштабируются внутри своих ячеек.
- **«Скопировать текущий»** = сохранение пресета без миниатюры.
- **Миниатюра**: `get_viewport().get_texture().get_image().save_png(...)` + текстовый патч `.tres` (ResourceSaver не видит несохранённый/неимпортированный png той же сессии); при пересохранении слота старый `.jpg` удаляется, ссылка правится на `.png` (слоты 01–05 исторически `.jpg`).
- Поля цвета маппятся на поля пресета явно через `COL_FIELDS` (по полю, не replace-цепочкой).

## 5. Отклонения от ТЗ и правки данных (честно)

1. **Нет Godot в песочнице** → движковые шаги заменены статанализом/CPU-зеркалами; см. §6.
2. **Исходный harness из Приложения А в репозитории отсутствовал** → `sky_gradient_check.py` воссоздан по описанию; калибровка — контрольные числа «before» (4/20 K4, 4/20 K0) сошлись.
3. **K0: `col_glow == col_horizon` побитово** (источник B) → H: `col_horizon = glow × 0.92` = (0.045473, 0.210318, 0.639222).
4. **K1: немонотонность L** (band темнее horizon в источнике B) → перенесён как есть (честность переноса), исправлен в H: `col_band × 1.25` = (0.231044, 0.114753, 1.223043).
5. **K3–K6: идентичные формы p1..p5** → H: K3=(0.011, 0.078, 0.158, 0.305, 0.525), K5=(0.010, 0.072, 0.150, 0.290, 0.505), K6=(0.008, 0.060, 0.130, 0.260, 0.470); K4 оставлен эталоном. Все зазоры ≥ 0.01.
6. **Материал: первое окно рампы было «мёртвым»** (sk_horizon слишком тёмный) → H: `sk_horizon = (1.78, 0.0707, 0.0325)` (п. 17.6).
7. **Критерий `check_set` сужен**: по ТЗ предупреждение при совпадении формы И цветов, но у K3–K6 палитры разные — проверка не срабатывала бы никогда. Реализовано: предупреждение за одинаковые формы p1..p5 у наполненных пресетов; свободные слоты (`light == null`) исключены (иначе их дефолтные формы == K4 давали бы ложные срабатывания). Формулировка в `_run_set_check` панели приведена в соответствие.
8. **Панель 794 строки против ~600 в ТЗ**: CPU-зеркало рампы, таблица L(u), интеграция валидатора и текстовый патч миниатюры.
9. **Фаза D, знак ориентации света**: сохранён по статанализу п. 12.3 — `Basis.looking_at(−direction)`, при |dot(up,dir)|>0.98 полюс up=FORWARD.
10. **Фаза G сверх списка**: удалён `q_tools/sim_debug_ui.gd` (ссылался на удалённые контроллеры — мёртв после 17.2); архивные скрипты вуали переименованы `.gd → .gd.orig` (иначе grep живого кода 18.2 ловил `set_shader_parameter` в архиве); `cloud_large_v1/cloud_detail_v2` фактически лежали в `Assets/sky/textures/`, а не `Assets/sky/` (пути в чеклисте уточнены по факту); `AIDebugLogPanel.gd` упоминает `SkyDebugUI` только в комментарии — оставлен (приёмочные grep чисты).

## 6. Невыполнимое без Godot (зафиксировано)

- **G.3**: переимпорт проекта и пересборка — невыполнимы (нет движка). `.uid`-файлы и `.import`-метаданные перенесены текстом; при первом открытии в Godot 4.7 ожидается штатный реимпорт.
- Скриншоты «до» (шаг 0.3), компиляция шейдера, runtime панели и headless-тест `q_tools/test_sky_controllers.gd` (написан, не запущен).
- Замена: CPU-зеркала (harness, preset_check, зеркало валидатора), статические grep-проверки, вычитка `.tscn`/`.tres` парсером.

## 7. Поставка

Push невозможен (нет учётных данных GitHub в песочнице). Создан инкрементальный bundle от базового коммита:

```
git bundle create q733-sky.bundle fb1c41e..q733-sky
```

Применение у получателя (в клоне с `fb1c41e` в истории):

```
git fetch /path/to/q733-sky.bundle q733-sky:q733-sky
git checkout q733-sky   # либо merge в main
```

Дальше: открыть `Q7.32.PreOmega` в Godot 4.7, дождаться реимпорта, запустить `Основная_сцена.tscn` (или `SkyEnvironment/SkyTest.tscn`), проверить панель и пресеты, прогнать `q_tools/test_sky_controllers.gd` headless.
