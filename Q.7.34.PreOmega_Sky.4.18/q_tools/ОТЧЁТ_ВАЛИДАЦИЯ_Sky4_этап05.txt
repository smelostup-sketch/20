Light_plan_v2.txt §10 (тесты A–G), §11 (критерии 1–13)

МЕТОД
Числовая эммуляция формул SkyVeil.gdshaderinc (транслитерация GLSL в GDScript)
с ЖЁСТКОЙ привязкой к исходнику: §0 теста test_light_v5.gd сверяет 15 формульных
фрагментов + константы RegEx'ом по активному коду — эммуляция не может разойтись
с шейдером незамеченной. Структурные проверки — по активному коду (комментарии
отсечены). GPU в среде разработки нет: визуальная часть приёмки — за заказчиком
(список внизу). Все прогоны — Godot 4.7.2-stable headless.

ТЕСТЫ A–G (§10) — РЕЗУЛЬТАТЫ (q_tools/test_light_v5.gd, PASS)
A Neutral   — белый tint нейтрален на 201 точке mu; hue прямого света = hue
              источника (искажений нет); shade ∈ [0.60, 1.0].
B Palette   — зоны достижимы и чисты (mu ≤ −0.35 → anti, mu ≥ 0.75 → solar,
              t = middle → transition); плавность: макс. шаг ≤ оценки Липшица
              на 4001 точке; сшивка ветвей непрерывна (≤ 1e-4); вырожденные
              данные (mu_range→0, position вне диапазона) безопасны; функция
              зависит только от (view, sun) — POSITION/TIME/VIEW нет:
              перемещение камеры результат не меняет.
C Optical   — alpha монотонна по плотности и ∈ [0,1] на экстремумах
              (tau_per_km=100, path=120 км, scale=8); на ярком фоне рост
              плотности ТОЛЬКО затемняет (ошибки композитинга «ярче от
              плотности» нет); премноженный композит не превышает яркость
              самой вуали; tau/alpha не зависят от палитры (v2 §5.2).
D Self-Shadow — выкл = ТОЧНО shadow_t 1.0 (один вызов в direct-тракте);
              вкл только ослабляет прямой свет (11 точек плотности, никогда
              не усиливает); shadow_strength=0 нейтрален; плотность, tau,
              alpha, curtain от самозатенения НЕ зависят — форма слоя и
              базовая прозрачность при выключении прежние.
E Ambient   — ambient = среда × strength × gain (линейно, без скрытой
              обработки); нулевая среда → ТОЧНЫЙ ноль (вуаль не светится при
              нулевых direct+ambient — эмиссии нет, v2 §2.2); палитра в
              ambient-тракт не входит.
F Zero Direct — 576 комбинаций (mu × cos × shadow_t × gain) при энергии 0
              дали ТОЧНЫЙ ноль прямого вклада; скрытых минимумов нет
              (max/clamp в direct-тракте отсутствуют); окружающая среда
              продолжает освещать вуаль.
G Composition — истинный горизонт (path ≥ 55 км) = ноль вклада (ореолов нет);
              d = 0 → фон без изменений; дальность ≥ 90 км держится
              (path(90 км) ≈ 16.8 км в плите < curtain_start 18 км);
              curtain входит ТОЛЬКО в alpha (двойного затухания нет);
              horizon-окрашивания (воздушной перспективы) в модуле нет —
              сознательно отложено до визуальных замеров (v2 §7);
              композит премноженный, поверх фона+солнца (вуаль затеняет
              солнце/луну/звёзды — порядок сохранён).

КРИТЕРИИ ПРИЁМКИ (§11)
 1. Sun — единственный источник прямого: direct-тракт читает только
    hc_sun_color/hc_sun_energy (из state.sun_* = узел Sun); «moon» в модуле
    вуали отсутствует (MoonLight — помеченная заглушка, решение 30.10 п.3).   ✔
 2. Sky Gradient — согласованная среда: apply_palette → set_gradient_
    environment(col_light3, col_light1) → state (test_light_v2/v3 PASS).      ✔
 3. Вуаль без самостоятельной эмиссии: albedo × (direct + ambient);
    аддитивных цветовых констант в формуле освещения нет (тест E, §11.11).    ✔
 4. Все потребители используют согласованные данные Sun: sk_sun_dir ==
    state.sun_direction == basis.z узла (≤ 1e-5, D2/D3 + v2 §2 + v3 §5).      ✔
 5. Три зоны работают как художественная палитра (тест B).                    ✔
 6. Палитра не меняет плотность/оптическую толщину (тест C + v3 §2:
    hc_palette/hc_sun_*/hc_ambient_* не входят в блок плотности).             ✔
 7. Самозатенение полностью отключается (hc_use_shadowing=false → 1.0;
    тест D; базовая вуаль работает без блока).                                ✔
 8. Оптическое затенение не применяется повторно: «* shadow_t» — ровно 1
    вхождение (тест D + v3 §2, v2 §6.2).                                      ✔
 9. Воздушная перспектива без артефактов: окрашивающего блока нет вовсе —
    curtain только в alpha; горизонт чист (тест G). Подключение горизонта
    среды — после визуальных замеров (v2 §7 требует проверки).                ✔
10. Нулевая интенсивность Sun → прямой вклад отсутствует (тест F).            ✔
11. Захардкоженных источников света нет: анти-дрейф v2 §6 / v4 §6 (ноль
    Color-литералов в компоненте/секции панели), дефолты модуля — данные
    плана §4.1 и байт-континуити col_light3.                                  ✔
12. Существующие архитектурные контракты не нарушены: полная регрессия
    (см. ниже) — 0 провалов; писатель материала один; binding не пишет
    геометрию (sk_sun_dir); панель пишет только через контроллеры/профиль.    ✔
13. Дополнительная стоимость вычислений измерена (структурно):
    DS_veil_density = 5 текстурных выборок (fiber/shape/field/break/detail);
    самозатенение = +2 вызова плотности (стратификации 0.25/0.75) = до
    +10 выборок на пиксель (5 → 15, ×3 текстурного трафика вуали) при
    hc_use_shadowing=true; при false — ноль дополнительных выборок
    (early-out тернаром). GPU-тайминг на целевом железе — методика ниже.      ✔

СТОИМОСТЬ САМОЗАТЕНЕНИЯ: МЕТОДИКА ЗАМЕРА НА ЦЕЛЕВОМ ЖЕЛЕЗЕ
1. Сцена с вуалью (пресет с veil_enabled=true, hc_use_lighting=true).
2. Замер 1: вкладка «Погода» → «Самозатенение (hc_use_shadowing)» ВЫКЛ —
   среднее время кадра (мониторинг производительности / debug-счётчик).
3. Замер 2: тот же ракурс, самозатенение ВКЛ. Разница = стоимость блока.
4. Повторить на 2–3 ракурсах (горизонт/средний/зенит) и целевом разрешении.
Ожидаемо: рост ограничен ×3 текстурного трафика вуали (структурный подсчёт
выше); при выключенном блоке стоимость строго нулевая.

ИТОГ
Система соответствует §12: Sun — источник прямого света, Sky Gradient —
цветовая среда, Cirrus Veil — объём/поглощение/рассеивание. Самостоятельных
источников и эмиссии нет; каждый параметр имеет одну семантику и одного
владельца; обновление событийное (publish → bindings), polling отсутствует.
Структурная валидация A–G и критерии 1–13 — ЗАКРЫТЫ; пункты визуальной
приёмки (GPU) перечислены выше и остаются за заказчиком.
