## 1. Родословная бага хоткеев Q7.29 (признано)
| Причина | Где | Следствие |
|---|---|---|
| node-typed экспорт `@export var controller: TimeOfDayController` + присваивание NodePath в рукописном tscn | Scripts/Environment/SkyDebugPreview.gd + Сцена_неба.tscn | Godot не конвертит NodePath→Object: controller=null, любой ключ — early return |
| узла превью нет в Основной_сцене | Основная_сцена.tscn | в игре клавиш неба не существовало вовсе |

Фикс: SkyDebugUI.gd с `@export var controller_path: NodePath` (проектный паттерн
light_path/player_path/BushGrassComponent.player_path), узел в обеих сценах,
стенд sim_debug_ui проверяет резолв и в Сцене_неба, и в Основной_сцене.

## 2. Панель (SkyDebugUI)
- Клавиша 0 — показать/скрыть. Скрыта по умолчанию → геймплею не мешает.
- Состав: статус-строка (фаза / переход / авто / качество / покрытие / ветер);
  кнопки ЗАКАТ, СУМЕРКИ, НОЧЬ (плавный переход 3 с; чекбокс «мгновенно» →
  set_phase_instant); чекбокс «автопрогресс фаз»; чекбокс «качество
  (деталь+гало)»; слайдер «облака (покрытие)» 0..0.95 шаг 0.01; слайдер
  «ветер (×скорость)» 0..5 шаг 0.05; подписи чисел у слайдеров.
- Построена кодом (CanvasLayer layer=100 → PanelContainer → VBox): рукописный
  tscn не резолвит node-typed экспорты; программная сборка детерминирована.
- Событийность: только InputEventKey(0) и сигналы Control (pressed/toggled/
  value_changed/drag_started/drag_ended). Таймеров НЕТ (контракт).
- Петля исключена: программная установка слайдера идёт под флагом _syncing
  (value_changed не толкает контроллер); ручное изменение тянет
  debug_set_coverage/debug_set_wind_multiplier сразу.
- Sync наружу: если контроллер поменяли мимо панели, слайдеры догоняют в
  _process, кроме состояния «слайдер тянут рукой» (drag_started/drag_ended).
- Безопасность: пустой/битый controller_path = push_warning + нога без панели,
  клавиша 0 и обращения — no-op (стенд: check «broken»).
- Цифровых хоткеев 1–9 БОЛЬШЕ НЕТ (конфликтов с геймплеем не было, но панель
  закрывает все нужды; решение по жалобе заказчика).

### 3.1 Швы: зеркальная замостка в шейдере
```glsl
float cloud_sample(sampler2D tex, vec2 uv) {
    vec2 m = mod(uv, 2.0);
    return texture(tex, 1.0 - abs(1.0 - m)).r;
}
```
Треугольная волна периода 2: значение C0-непрерывно на границе плитки (линии
нет), производная меняет знак — на шумовых облаках незаметно. Все 5 облачных
сэмплов (n1, detail, n3, detail2, shade) переведены на cloud_sample.
Оригиналы автора НЕ правим. Когда придёт обещанная бесшовная текстура мелких
облаков — возврат к `texture()` правкой одной функции.

### 3.2 Уровни: технические производные (оригиналы нетронуты)
`Assets/sky/textures/cloud_large_v1.png` (из v1), `cloud_detail_v2.png` (из v2):
растяжение уровней до полного диапазона + гамма γ, решённая бисекцией из
условия «linear-средняя производной = linear-средняя калиброванного слоя
Q7.29» (ручки покрытия/плотности/детали сохраняют смысл):
- v1: γ=0.6341 → 0.086→0.206;
- v2: γ=0.8906 → 0.196→0.239.
Честное отличие: после гаммы хвосты распределения полнее референса
(frac>0.55: 0.087 против 0.032) — при том же покрытии облака чуть плотнее/
контрастнее; характер (кучевость v1, дымность v2) сохранён. Крутится слайдером
покрытия на панели вживую. Откат: в omega_sky_material.tres вернуть пути
cloud_noise_large.png / cloud_noise_detail.png (файлы в папке оставлены).
Материал сейчас: cloud_large_tex=cloud_large_v1.png, cloud_detail_tex=
cloud_detail_v2.png.
