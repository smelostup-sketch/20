# AUDIT.md — шаг 0, read-only аудит `Q7.32_SKYprav_3.1` (2026-10-23)

Метод: sparse-клон (5.1 МБ), чтение кода, headless-прогон Godot 4.7-stable official. Код не модифицирован (правки шага 1 — отдельно, в CHANGELOG).

## 1. Движок и структура
- **Godot 4.7-stable, Forward Plus** (`config/features=PackedStringArray("4.7", "Forward Plus")`). Проверено официальным бинарём 4.7.stable.official.5b4e0cb0f.
- **Корень проекта = `Q7.31_SKY.RengarPreOmega/`** (там `project.godot`), папка Q7.32 — компонент внутри. Autoload продакшна: `SettingsService` из `res://Scripts/UI/SettingsService.gd` (вне Q7.32); **сцена Q7.32 от него не зависит** → harness-проект без autoload корректен.
- **Q7.32 самодостаточен**: все `ext_resource` сцены/tres указывают внутрь папки; шумы — сырые `.bin` + `CloudTextureLoader` (спайк B1: ResourceSaver для ImageTexture3D в 4.7 сломан, поэтому .bin + сборка Array[Image] один раз, 6 мс).
- Пути сцены абсолютные `res://Q7.32_SKYprav_3.1/...` → harness и zip повторяют эту структуру (корень проекта содержит папку с этим именем).

## 2. Небо и цвет
- `omega_clouds_test_sky.tres`: Sky, **process_mode=2 (INCREMENTAL)** → кубмап неба доживает за N кадров; скриншотам нужна выдержка (в панели 40 кадров).
- Environment сцены: background_mode=2 (sky), ambient_light_source=3 (sky), **tonemap_mode=2 = FILMIC**.
- **Находка F1:** во всех сценах репозитория (тест, `Основная_сцена`, `Сцена_неба`) tonemap = **Filmic**, не ACES, хотя в инструкциях значится ACES. Решение отложено до шага 2: (а) считать «текущим» Filmic и адаптировать палитру под него; (б) переключить на ACES (3) и адаптировать под ACES. Утилита инверсной компенсации шага 2 работает с любой из кривых (численный инверс фактической).
- Освещение облаков сейчас: HG-фаза + powder + ms_gain, ambient-градиент far/near lerp по высоте, самозатенение тапами к солнцу — база для шага 5 (рестайл в ColorRamp по освещённости, D3).

## 3. Бенч
- `CloudsTestBench.gd`, 3093 строки: свой UI-слой (CanvasLayer, слайдеры/кнопки), профили Perf/Balanced/Quality/Reference, режимы 0–6, тур-тесты, численные зеркала `cloud_radiance()` (sun/ambient/ms по членам) — сильная база.
- Солнце: конвенция `sync_sun_from_light` — бенч читает направление из DirectionalLight3D каждый кадр; вращение света = F1. Панель шага 1 использует ту же конвенцию (пишет свет, читает read-only синк).
- Чего не было (добавлено шагом 1): референсы на экране, пресеты состояний, экспорт скриншотов.
