# Q7.32.PreOmega.BENCH — тестовый стенд, панель SkyLab и инструменты

Упаковано шагом 1 (2026-10-25) из `Q732_SKY_v0.5.3/Q7.32_SKYprav_3.1/`.
Инструментарий разработки неба — вне оставляемого состава (вуаль + градиент + свет).
Минимальную замену для визуальной проверки в составе несет `VeilSkyRig.gd` + `Сцена_неба_тест.tscn`.

| Файл | Что это |
|---|---|
| `CloudsTestBench.gd` (+ .uid) | Стенд (3102 стр.): UI-слой (клавиша 9), профили Perf/Balanced/Quality/Reference, режимы 0-12, тур-тесты, CPU-зеркала формул (density/radiance/hc-слой/солнце), загрузка шумов .bin |
| `SkyLabPanel.gd` (+ .uid) | Панель SkyLab (клавиша 8/F8): состояния ref1-ref5, t-блендер палитр M1, слайдеры солнца, экспорт скриншотов (F9) |
| `SkyLabMirror.gd` (+ .uid) | Численное зеркало освещения SKYLAB v0.4/v0.5 (шаг 5/6) для самотестов |
| `gen_noise3d.gd` (+ .uid) | Офлайн-генератор 3D-шумов (seed фиксирован, побайтово воспроизводим) — источник noise_pw_128.bin / noise_worley_32.bin |
| `skylab_palette_tool.gd` (+ .uid) | Адаптация палитр M1 под Filmic (численный инверс кривой тонмаппинга Godot 4.7) |
| `Сцена_облаков_тест.tscn` | Старая тестовая сцена стенда (ссылалась на бенч/панель/карточки — в архиве пути не разрешаются) |

Шаг 1.1 (2026-10-25): логика состояний ref1-ref5/t-блендера/солнца/скриншотов из
SkyLabPanel.gd и меню «Вуаль (SKYHC)» + пресеты A/B из CloudsTestBench.gd ПЕРЕНЕСЕНЫ
в `VeilSkyPanel.gd` рабочего состава (урезаны под состав без кучевых/карточек;
палитры и пресеты — дословно). Оригиналы здесь остаются полной точкой возврата.

Внимание: скрипты ссылаются путями `res://Q7.32_SKYprav_3.1/...` — при восстановлении
вернуть их в папку компонента. Бенч рассчитан на ПОЛНЫЙ шейдер v0.5.3 (кучевые) —
с урезанным шейдером режимы кучевых неприменимы (оригинал шейдера — в CUMULUS-паке).
